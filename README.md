# Atlante Micologico di Pescopennataro — WebGIS

Release pubblica minima, derivata dal progetto WebGIS_V6.

## Avvio locale
Avviare un server HTTP nella cartella e aprire `index.html`. Non aprire il file con doppio clic (`file://`).

## Contenuto
- codice modulare dell'applicazione;
- configurazioni pubbliche;
- GeoJSON dei rilievi e degli habitat;
- fotografie ottimizzate per il Web;
- loghi e immagini effettivamente distribuiti.

Sono esclusi workspace QGIS, GeoPackage, KMZ, backup, repository `.git`, documentazione interna e archivi legacy.
